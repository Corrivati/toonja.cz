WordPress a Webflow odzvonilo. Malé weby dnes stavím přes Git a AI

Na malý web už nepotřebujete WordPress ani Webflow. Stačí Git repozitář, statický web a AI asistent, který do něj přes MCP sahá za vás. Platíte jen doménu, hosting máte zdarma a změnu textu máte hotovou dřív, než byste si vzpomněli na heslo do administrace.

Tenhle článek čtete na webu, který jsem před pár dny přestěhoval z Webflow do Gitu. A kamarádovi Radkovi jsem ve stejných dnech přestěhoval web z WordPressu. Obojí bez najatého vývojáře. Tady je, co jsem cestou zjistil.

Proč WordPress a Webflow přestávají dávat smysl

WordPress i Webflow vznikly kvůli jedné věci: aby web mohl upravovat i člověk, který neumí kód. Tuhle práci dnes zvládne AI. A s ní padá hlavní důvod, proč za administraci platit.

Dobře, WordPress tu s námi ještě pár let bude. Fax taky. Ale podívejte se, co s sebou obě platformy táhnou:

  • WordPress: pluginy, aktualizace, bezpečnostní díry, page buildery, které generují kód jako z jiného tisíciletí. Hosting, který musí běžet pořád, i když web navštíví deset lidí denně. Plugin na formuláře, plugin na SEO a plugin na zrychlení webu, který zpomalily ty předchozí.
  • Webflow: hezký editor, ale platíte za každý web i za každé místo v týmu. Dnes od 15 do 25 dolarů měsíčně za web při ročním placení a 39 dolarů za plné místo v editoru (ceník Webflow). A obsah z něj dostanete ven jen s námahou.
  • Šablony: kupujete hotový design, dostanete i jeho zbytky. Stránky, které nepoužíváte, a funkce, které nefungují.

Když upravujete web párkrát do měsíce, platíte hlavně za pohodlí, které už nepotřebujete.

Co dělám místo toho: Git, MCP a AI

Web je obyčejná složka souborů na GitHubu. Upravuje ji AI asistent, publikuje ji hosting zdarma. Žádná databáze, žádná administrace.

Jak to vypadá v praxi:

  1. Obsah žije v Gitu. Texty, design i obrázky jako obyčejné soubory: HTML, CSS, případně Markdown. Celé to leží v repozitáři na GitHubu.
  2. AI do něj sahá přes MCP. MCP (Model Context Protocol) je „zásuvka“, přes kterou se AI asistent jako Claude nebo ChatGPT připojí k vašemu repozitáři. Napíšete „přidej na stránku kurzu nový termín“ a on to udělá.
  3. Každá změna je commit. Víte, kdo co kdy změnil. Když se něco pokazí, vrátíte to jedním krokem.
  4. Hosting si web postaví sám. Po každé změně se web automaticky publikuje, třeba na Cloudflare nebo GitHub Pages.

Vy tedy neklikáte v editoru. Vy zadáváte práci. Jako byste měli webaře, který nespí a neúčtuje si hodinovku.

Dvě zkušenosti z praxe

toonja.cz: z Webflow do čistého HTML

Můj web běžel na Webflow šabloně pro online kurzy. Krásně vypadala. Jenže pod kapotou zůstaly zbytky šablony a košík, který nefungoval. Ze 26 adres v sitemapě bylo skutečných jen asi 8. Zbytek byli duchové po šabloně.

Co jsem udělal:

  • Celý web jsem s AI převedl z Webflow do čistých HTML souborů. Žádný build, žádná databáze, žádný npm install.
  • Vzhled zůstal. Ze šablony jsem vyhodil skryté prvky, ukázkové kurzy a nefunkční košík, opravil odkazy a české texty.
  • Web hostuje GitHub Pages, zdarma.
  • Formuláře posílá externí služba, protože statický web je sám neumí.

radekrosastrong.cz: z WordPressu do Gitu

Radek je silový trenér a kamarád, jeho web najdete na radekrosastrong.cz. Potřeboval lépe prodávat workshop Svalové kontrakce. Začali jsme redesignem jedné stránky kurzu a skončili převodem celého webu.

  • Celý web je teď v Git repozitáři napojeném na MCP.
  • Hlavička a menu zůstaly beze změny, tak to Radek chtěl.
  • Radek si teď web spravuje sám přes ChatGPT, bez přihlašování do WordPressu, bez aktualizací pluginů.

Radkův web už nepotřebuje žádné aktualizace. Radek potřebuje jen trénovat.

Co tím získáte

Hlavně čas a peníze. Malý web v Gitu stojí jen doménu a úprava, která dřív trvala odpoledne, zabere pár minut.

WordPress Webflow Git + MCP + AI
Provoz placený hosting, pluginy od 15 USD měsíčně za web + místa v týmu hosting zdarma, platíte doménu
Úprava textu přihlásit, najít, kliknout, uložit přihlásit, najít, kliknout, publikovat napsat jednu větu AI
Údržba aktualizace jádra a pluginů žádná, ale jste v jejich systému žádná, web jsou statické soubory
Bezpečnost častý cíl útoků řeší Webflow není co hacknout, žádná databáze ani admin
Historie změn omezená omezená každá změna v Gitu, návrat jedním krokem
Vlastnictví data u hostingu data u Webflow soubory máte u sebe

A pár věcí navíc:

  1. Rychlost webu. Statické stránky se načítají okamžitě. Google i návštěvníci to ocení.
  2. Hosting zdarma doopravdy. Třeba na Cloudflare jsou požadavky na statické soubory zdarma a bez limitu (ceník Cloudflare Workers).
  3. Hromadné změny. Opravit překlep na 30 stránkách nebo přidat meta description všude je jedno zadání, ne jedno odpoledne.
  4. Žádná závislost na platformě. Zdražení nebo změnu podmínek přežijete. Repozitář přestěhujete jinam za hodinu.

Pro koho to je: záleží na velikosti webu

Pro malé a střední weby, které upravuje jeden až dva lidé, je Git + AI dnes nejlepší volba. Čím víc lidí a změn denně, tím víc dává smysl nějaká forma CMS.

Typ webu Co bych zvolil
Osobní web, web trenéra, řemeslníka, konzultanta Git + MCP + AI, bez debaty
Firemní prezentace, blog, kurzy (desítky stránek) Git + MCP + AI, k tomu služba na formuláře a platby
Web, kam denně publikuje redakce nebo netechnický tým Git + headless CMS (např. Decap CMS nebo TinaCMS), obsah zůstává v repozitáři, ale má editor
E-shop Shopify. Šablonu držíte v GitHubu, Shopify si ji synchronizuje samo a upravujete ji přes AI stejně jako web.
Velký web s rolemi, schvalováním a desítkami editorů CMS zůstává, AI pomáhá s obsahem a kódem

Pro zvídavé, z čeho se dá skládat:

  • Generátor webu: Astro, Hugo, Eleventy. Nebo úplně obyčejné HTML.
  • Hosting: Cloudflare, GitHub Pages, Netlify, Vercel. Pro malý web všechny zdarma nebo skoro zdarma.
  • AI asistent: Claude (v aplikaci s MCP nebo jako Claude Code) nebo ChatGPT, případně editory jako Cursor. Funguje to s tím, co už používáte.

Na co si dát pozor

Není to kouzelná hůlka. Pořád potřebujete někoho, kdo ví, co chce. Pár věcí, které se vyplatí pohlídat:

  1. Kontrolujte výsledek. AI je jako nadšený junior: hotovo má za minutu, včetně věcí, o které jste nežádali. Než změnu pustíte ven, mrkněte na náhled. Git vám sice dovolí vrátit se zpátky, ale lepší je chybu nepublikovat.
  2. Formuláře, platby a přihlášení statický web sám neumí. Potřebujete na ně službu třetí strany (formulářovou službu, platební bránu).
  3. Klient bez editoru. Pokud web předáváte někomu, kdo chce klikat, ne psát zadání, zvažte headless CMS.
  4. Přístupy hlídejte. AI dostane k repozitáři práva zápisu. Dejte jí jen ten jeden repozitář, ne celý účet.
  5. Licence šablon. Když stěhujete web z placené šablony, nekopírujte její kód. Vzhled si nechte postavit znovu.
  6. SEO při stěhování. Zachovejte adresy, nebo nastavte přesměrování. Jinak přijdete o pozice, které jste roky budovali.

Jak začít

Žádný velký třesk. Starý web vám běží, dokud nový není hotový.

  1. Udělejte inventuru. Projděte sitemapu a zjistěte, které stránky opravdu žijí. U mě to byla necelá třetina.
  2. Založte repozitář na GitHubu. Soukromý, pro malý web zdarma.
  3. Připojte AI. Napojte Clauda, ChatGPT nebo jiného asistenta na repozitář přes MCP.
  4. Vytáhněte obsah. Nechte AI převést stávající stránky do HTML nebo Markdownu. Texty rovnou opravte.
  5. Postavte web. Zadejte vzhled slovy, ukažte starý web jako referenci. Kód šablony nekopírujte.
  6. Napojte hosting. Propojte repozitář s Cloudflare nebo GitHub Pages, ať se web publikuje sám.
  7. Přepněte doménu. Až je nový web hotový, přesměrujte DNS a nastavte přesměrování starých adres. Starý systém nechte chvíli běžet jen pro čtení.

Časté otázky

Musím umět programovat? Ne. Musíte umět jasně říct, co chcete, a zkontrolovat výsledek. Což je mimochodem těžší, než se zdá. Zeptejte se kteréhokoli webaře. Základní orientace v Gitu se hodí, AI vás ji ale naučí za pochodu.

Je to opravdu zdarma? Pro malý web skoro ano. Platíte doménu a předplatné AI asistenta, které stejně používáte na jinou práci. Hosting statického webu je u velkých poskytovatelů zdarma.

Co když AI něco rozbije? Každá změna je v Gitu. Vrátíte ji jedním krokem. Proto taky doporučuju dívat se na náhled před publikací.

Vyplatí se stěhovat fungující web na WordPressu? Pokud vás netrápí cena, údržba ani bezpečnost, nespěchejte. Pokud ano, vyplatí. Nejlepší chvíle je redesign: stejně budete web přestavovat.

Zvládne to i e-shop? Pro e-shop je top volba Shopify. Košík, platby a hosting řeší Shopify, šablonu držíte v GitHubu a upravujete ji přes AI úplně stejně jako web.

Chcete z WordPressu nebo Webflow taky odejít a nevíte, kde začít? Napište mi. Projdeme váš web a řeknu vám na rovinu, jestli to u vás dává smysl.
