Krátká odpověď

Statický web je web složený z hotových HTML souborů, které server jen pošle návštěvníkovi. Při návštěvě se nic nepočítá a nepotřebuje databázi ani administraci. Díky tomu se načítá rychle, hosting bývá zdarma a útočník nemá kudy se dostat dovnitř, protože žádná administrace prostě neexistuje.

Statický a dynamický web jednoduše

Představte si bistro. Dynamický web vaří každé jídlo na objednávku: při každé návštěvě poskládá stránku z databáze, šablony a pluginů. Tak funguje třeba WordPress.

Statický web má jídlo připravené předem. Stránka je hotová a jen se vydá. Rychleji, levněji a bez kuchaře, kterého je potřeba hlídat.

Statický neznamená neměnný. Obsah upravujete jako jinde, jen se změna připraví dopředu a pak se nahraje celá hotová stránka.

Jak statický web vzniká

  1. Ručně psané HTML. Nejjednodušší cesta. Hodí se pro menší weby, hlavně když vám s úpravami pomáhá AI.
  2. Generátor statických stránek. Texty píšete v Markdownu, nástroj jako Astro, Hugo nebo Eleventy z nich postaví hotové stránky.
  3. Hosting. Soubory nahrajete na GitHub Pages, Cloudflare nebo Netlify. Napojené na Git se publikují samy po každé změně.

Z praxe: toonja.cz

Tenhle web je statický. Obyčejné HTML soubory na GitHub Pages, žádný build, žádná databáze. Když jsem ho převáděl z Webflow, zjistil jsem, že ze 26 adres v sitemapě bylo skutečných jen asi 8. Zbytek byly pozůstatky šablony.

Co statický web sám neumí, řeší externí služba. Formuláře mi posílá FormSubmit, stránky slovníku generuje malý skript. Výsledek jsou ale zase obyčejné HTML soubory. Celý příběh přestavby najdete v článku WordPress a Webflow odzvonilo.

Kdy se statický web nehodí

  • E-shop. Košík, platby a sklad potřebují server. Tady sáhněte po Shopify.
  • Přihlašování a členské sekce. Bez služby třetí strany to nepůjde.
  • Redakce, která publikuje denně. Pokud web upravuje víc netechnických lidí, zvažte headless CMS. Obsah zůstane statický, ale editor bude mít administraci.
  • Vyhledávání a formuláře zvládnete, jen přes externí službu nebo skript v prohlížeči.
