Krátká odpověď

DNS (Domain Name System) je systém, který překládá názvy domén na adresy serverů. Když do prohlížeče napíšete název webu, DNS zjistí, na kterém serveru běží. Pomocí DNS záznamů nastavujete, kam míří web, kam chodí e-maily a jak doménu ověří různé služby.

DNS jednoduše

Lidé si pamatují jména, počítače čísla. DNS je převodník mezi nimi. Jako kontakty v telefonu: hledáte „Máma“, telefon vytočí číslo.

Doména a hosting jsou proto dvě různé věci. Doménu si koupíte u registrátora, web běží na hostingu a DNS je propojí.

Nejčastější DNS záznamy

  • A a AAAA: doména míří na IP adresu serveru (IPv4 a IPv6).
  • CNAME: doména míří na jinou doménu. Typické pro „www“.
  • MX: kam doručovat e-maily.
  • TXT: textové záznamy pro ověření domény a ochranu e-mailů (SPF, DKIM, DMARC).
  • TTL: není záznam, ale jeho vlastnost. Jak dlouho si ho ostatní servery pamatují.

Příklad: jak běží toonja.cz

Doména toonja.cz je registrovaná u českého registrátora, ale web běží na GitHub Pages. V repozitáři webu leží soubor CNAME s adresou www.toonja.cz. Podle něj GitHub ví, na jaké doméně má web obsluhovat. U domény pak DNS záznamy míří na servery GitHubu.

Při přechodu z Webflow se na straně domény měnilo jen to, kam DNS záznamy míří. Obsah se stěhoval zvlášť, do repozitáře. Postup popisuju v článku WordPress a Webflow odzvonilo, v kroku „Přepněte doménu“.

Na co si dát pozor

  • Nesmažte MX záznamy. Při přepínání webu se snadno rozbije e-mail, který na webu vůbec nezávisí.
  • Snižte TTL předem. Den před změnou, aby se nové nastavení rozšířilo rychle.
  • Staré adresy přesměrujte. Nový web na nové platformě často mění URL. Pomůže přesměrování 301.
